# AVI 转 MP4 · 技术支持

把 AVI 视频转换为 H.264 + AAC 的 MP4，便于播放和保存。支持多选 AVI、队列转换，以及批量保存到系统相册。转换在设备本地进行，无需账号。

## 使用方法

1. 点击“浏览文件”，从“文件”、iCloud 或外接存储选择一个或多个 AVI。
2. 开始转换，转换期间保持应用在前台。1.0.1（11）起会自动选择输出质量，保留原始分辨率。
3. 转换结束后点击“全部保存到相册”，并允许添加照片权限。
4. 系统相册确认保存成功后，应用会自动清除对应的本地 MP4；保存失败时保留文件供重试。外部原始 AVI 不受影响。

## 常见问题

- **不能选择文件？** 文件选择器只允许 AVI。云端文件需要先由系统下载；这可能需要网络。
- **转换失败？** AVI 是容器格式，内部编码、文件损坏、空间不足可能影响转换。可以重试单个文件。
- **不能保存到相册？** 请在系统设置中检查添加照片权限，并确认有足够存储空间。
- **如何清理空间？** 应用的“本地存储”提供清理工具。手动清理前请确认需要保留的视频已存在于系统照片中。
